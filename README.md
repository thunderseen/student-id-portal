# e-Learning & Earning Ltd. - স্টুডেন্ট আইডি কার্ড ব্যাকএন্ড ও অ্যাডমিন স্টুডিও

এই প্রজেক্টটিতে **ফ্রন্টএন্ড ওয়েবসাইট** এবং **নিজস্ব ডাটাবেস ব্যাকএন্ড (Node.js/Express)** সম্পূর্ণ একসাথে প্রস্তুত করা আছে।

## 🌟 কেন এটি আপনার সেরা সমাধান:
1. **সবাই ফর্ম পূরণ করবে ওয়েবসাইটেই:** স্টুডেন্টরা তাদের মোবাইল ফোন দিয়ে ওয়েবসাইটে ঢুকে ফর্ম পূরণ করে **"আইডি কার্ড জমা দিন"** চাপলেই ডাটা সরাসরি সার্ভারের ডাটাবেসে জমা হয়ে যাবে।
2. **সব তথ্য ওয়েবসাইটেই থাকবে:** কোনো গুগল শিট বা বাহ্যিক লিংকের ঝামেলা নেই, সব কার্ড সার্ভারের `students_db.json` ফাইলে স্বয়ংক্রিয়ভাবে সেভ থাকবে।
3. **শুধু অ্যাডমিন দেখতে ও ডাউনলোড করতে পারবে:** সাধারণ স্টুডেন্টদের সামনে কোনো কার্ড লিস্ট বা ডাউনলোড অপশন থাকবে না। আপনি **Admin Panel** বাটনে ক্লিক করে পাসওয়ার্ড **`sabasagol`** দিলেই জমা হওয়া সবার কার্ড এক ক্লিকে **A4 Print Sheet** বা **Word (.docx)** ফাইলে ডাউনলোড করতে পারবেন।

## 🚀 ফ্রি অনলাইন হোস্টিং করার সহজ উপায় (Render.com - ২ মিনিটে লাইভ):
১. [Render.com](https://render.com)-এ ফ্রি অ্যাকাউন্ট খুলে **New Web Service** সিলেক্ট করুন।
২. এই ফাইলগুলো GitHub-এ আপলোড করে কানেক্ট করুন।
৩. Settings-এ:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
৪. **Deploy Web Service** চাপুন! Render আপনাকে একটি লাইভ ফ্রি ওয়েবসাইট লিংক দেবে (যেমন: `https://your-id-cards.onrender.com`)।
